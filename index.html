五個級距怎麼選？

需要五頁店家入口，選入門 42,000；缺照片與文案，選入門＋ 62,000；要品牌視覺與可編輯後台，選標準 88,000；以房型或空間吸引客人，選含立體導覽的進階 178,000；特定流程或工具選系統級 300,000 起，依規格報價。

創始建置 15,000 包含什麼？

交付內容與入門 42,000 相同：五頁、手機版、首年網域、主機、SSL、Google 商家綁定與 GA4。條件是同意把成品放進作品集，目前剩 3／10 名；第十一家起恢復 42,000。這是入門建置優惠，不包含入門＋的拍攝文案或其他高級距內容。剩餘創始名額第二年起網站維運同樣為 20,000／年。

第一年與第二年，各要付多少？

第一年按選定方案支付建置費，已含網域、主機與 SSL，不另收首年維運費。所有新案的網站維運第二年起 20,000／年，包含剩餘 3 個創始建置名額；已承諾舊客的 12,000／年依原約定。另選的拍攝、文案或其他加購會先列在報價單上。系統級維運、第三方服務與 API 費用依專案報價確認。

需要訂金嗎？多久交件？

入門、入門＋與標準不收訂金，上線驗收後付款；進階與系統簽約時收三成。入門與標準七個工作天交件；入門＋另確認拍攝排程與交期，進階約三週，系統依專案排程；實際交期在報價時確認。

我要準備什麼？沒有照片或文案怎麼辦？

我們先了解你的店家、服務與需求，再列出需要補充的真實資料與素材。半日拍攝 9,800，交付 30 張修圖照片；五頁文案代筆 15,000。入門＋ 62,000 已包含兩項，較入門再分開加購的 66,800 省 4,800。

網域到底算誰的？

你的。登記在你或你公司名下，帳號與權限交給你，這一點寫進合約。

以後改內容，費用怎麼算？

首年不另收維運費。續約維運含網域主機續約、備份、故障排除、每年兩次內容修改與每年一份健檢報告；換一張照片、改電話或調價格不算次數。續滿三年送一次改版或一次拍攝，具體範圍依報價確認；超出原有規格的功能先另行報價。

我自己能不能改？

標準與進階包含可自行編輯的後台；系統級的管理介面依確認規格製作。入門與入門＋不包含可自行編輯後台，可透過維運服務請我們協助修改。

我要修改，是不是得先學專有名詞？

不用。用文字說明想要的效果，附上圖片就可以。若不容易描述，也可以提供喜歡的網站畫面作為參考。

哪天不續約，東西怎麼拿？

網站檔案打包、網域交接到你名下，兩件都不收費；共用元件與系統工具依合約授權範圍使用。需要我們協助部署到新地方、設定 DNS 與交接教學，費用為 8,000，會先確認範圍再執行。
