五個級距怎麼選？

需要五頁店家入口，選入門 42,000；缺照片與文案，選入門＋ 62,000；要品牌視覺與可編輯後台，選標準 88,000；以房型或空間吸引客人，選含立體導覽的進階 178,000；特定流程或工具選系統級 300,000 起，依規格報價。

入門優惠碼怎麼使用？

僅入門 42,000 可使用旋賞私下發送的有效優惠碼，折抵 10,000，實付 32,000 元含稅。每案一次、不得與其他優惠併用、暫不設期限；由旋賞在報價階段人工確認核銷後列入正式報價。其他方案與年費不適用。

第一年與第二年，各要付多少？

第一年依選定方案支付含稅建置費，已含網域、主機與 SSL，不另收首年維運費。新案網站維運第二年起 20,000／年含稅，含每年兩次內容更新；已承諾舊客的 12,000／年依原約定。加購、系統級維運、第三方服務與 API 費用另行約定。

需要訂金嗎？多久交件？

所有方案訂金 30%，驗收後支付尾款 70%；交期依個案約定。正式報價有效 30 日，製作含兩輪整批修改，新增功能或超出範圍另行報價。

我要準備什麼？沒有照片或文案怎麼辦？

我們先了解你的店家、服務與需求，再列出需要補充的真實資料與素材。入門＋ 62,000 已含半日拍攝、30 張修圖照片與五頁文案；其他拍攝、文案需求依範圍另行報價，素材交付與使用權依合約約定。

網域到底算誰的？

你的。登記在你或你公司名下，帳號與權限交給你，這一點寫進合約。

以後改內容，費用怎麼算？

製作含兩輪整批修改。第二年起 20,000／年含稅的網站維運，含網域主機續約、備份、故障排除及每年兩次內容更新；照片、電話與價格調整納入內容更新額度。新增功能或超出範圍另報，系統維運、第三方與 API 費用另約。

我自己能不能改？

標準與進階包含可自行編輯的後台；系統級的管理介面依確認規格製作。入門與入門＋不包含可自行編輯後台，可透過維運服務請我們協助修改。

我要修改，是不是得先學專有名詞？

不用。用文字說明想要的效果，附上圖片就可以。若不容易描述，也可以提供喜歡的網站畫面作為參考。

哪天不續約，東西怎麼拿？

網域與客戶原始資料保留給客戶；網站程式碼、設計與交付使用權依合約約定。網站搬遷服務為 8,000 元含稅，搬遷、部署與交接協助的範圍先列入合約確認。
